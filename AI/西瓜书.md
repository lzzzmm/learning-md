# 第二章 模型评估与选择
## 检验误差与过拟合
错误率：分类错误的样本数占样本总数的比例
精度：1-错误率
误差：学习器实际预测输出与样本真实输出之间的差异
  - 训练误差/经验误差：训练集上的误差
  - 泛化误差：新样本上的误差

过拟合：训练集上效果好，测试集上效果不好，过拟合无法避免，只能缓解
欠拟合：训练集和测试集效果都不好

## 评估方法
- 留出法
  - 数据集划分为两个互斥集合（分层采用保留类别比例），一个作为训练集，一个作为测试集
  - 单次使用留出法的估计结果不可靠，通常是重复实验取平均作为留出法评估结果
  - 常见做法是2/3-4/5作为训练集，其他作为测试集
- 交叉验证法
  - ![2026-02-08-17-27-06.png](./images/2026-02-08-17-27-06.png)
- 自助法
  - 有放回取球的例子
  - ![2026-02-08-17-37-39.png](./images/2026-02-08-17-37-39.png)
  - 就是仍有估计1/3的数据没有在训练集中出现用于测试
  - 缺点：自助法产生的数据集改变了初始数据集分布，会引入估计偏差
    - 估计偏差：估计方法本身带来的偏差，即使样本再多、算得再认真，结果也会偏高或偏低（假设想估计一个班学生的平均身高：你只在篮球队里抽样，算出来的平均身高：175 cm，全班真实平均身高：168 cm 这个 175 cm 系统性偏高，原因不是运气，而是抽样方式有问题这就叫 有估计偏差）
    - 在初始数据量足够情况下，留出法和交叉验证法更常用
- 调参与最终模型
  - 参数分为：超参数、模型参数
    - 超参数
      - 是算法参数，数目常在10以内
      - 由人工设定多个参数候选值后产生模型（比如决策树的深度，叶子数等）
    - 模型参数：
      - 参数数目可能很多，比如深度学习模型可能有上百亿参数
      - 通过学习产生多个候选模型
      - 在模型选择完成后，学习算法和参数配置已选定（超参数），此时，应该用数据集D（所有数据集，因为前面的实验都是用的部分数据集做训练）重新训练模型，这个模型才是最终要交给用户使用的模型

## 比较检验
性能比较中涉及的几个重要因素
- 我们希望比较的是泛化性能，但使用评估方法我们获得的是测试集上的性能，二者对比结果未必相同
- 测试集上的性能与测试集本身的选择有很大关系，即便使用相同大小测试集，包含的样例不同，测试结果也会不同
- 很多机器学习算法本身具有一定随机性，即便用相同参数设置在同一个测试集上多次运行，其结果也会有不同

假设检验为学习器性能比较提供重要依据：若在测试集上观察到学习器A比B好，则A的泛化性能是否在统计意义上由于B，这个结论的把握有多大。


- 假设检验（默认用错误率为性能度量$\epsilon$）
  - 现实中我们不知道泛化错误率，只能获取测试错误率$\hat{\epsilon}$，泛化错误率与测试错误率未必相同，但直观上，二者接近的可能性比较大，所以可根据测试错误率估推出泛化错误率的分布
  - 两种最基本的假设检验

### 类别不平衡问题
正例比反例的数量大很多的情况，只要永远预测新样本为正例，准确率就特别高，但是这个是无效的模型

y作为概率，一般情况如果正反例数量差不多，决策规则是 $\frac{y}{1-y} > 1$ 预测为正例

当数目不同时，另$m^+$表示正例数，$m^-$表示反例数，只要$\frac{y}{1-y}>\frac{m^+}{m^-}$ 则预测为正例

上面两个例子就变成再缩放策略 $\frac{y^`}{1-y^`}=\frac{y}{1-y} * \frac{m^-}{m^+}$

几种比较经典的处理方式：
- 欠采样
  - 去除多的类别的数据量，让正反例数据接近
- 过采样
  - 增加一些正例/反例样本
- 阈值移动
  - 直接基于原始训练集进行学习，在用训练好的分类器进行预测时，将在缩放的公式嵌入到决策过程中

# 第四章 决策树
叶节点：决策结果
其他节点：对应一个属性测试，每个节点包含的样本集合根据属性测试结果被划分到子结点中

## 划分选择
选择哪个属性作为节点进行分叉，希望决策树的分支节点所包含的样本尽可能属于同一类别，即分叉纯度越高越好

### 信息增益
熵越小，有序程度越高

n个特征，一个个计算对应的熵，选哪个熵下降最多的特征作为分叉节点

### 增益率
信息增益对可取值数目较多的属性有所偏好，为减少这种偏好可能带来的不利影响，C4.5决策树算法不直接使用信息增益，而是使用信息增益率

![2026-02-28-23-30-51.png](./images/2026-02-28-23-30-51.png)

增益率准则对可取数目较少的属性有所偏好，因此，C4.5并不是直接选择增益率最大的候选划分属性，而是使用一种启发式：先从候选划分属性中找出信息增益高于平均水平的属性，再从选择中选择增益率最高的

## 剪枝处理
对付过拟合的一种手段

### 预剪枝
在决策树生成过程中，对每个结点在划分前进行估计，若当前节点的划分不能带来决策树泛化性能提升，则停止划分并将当前结点标记为叶子结点


### 后剪枝
先从训练集生成一颗完整决策树，然后从底向上对非也结点进行考察，若将该结点对应的子树替换为叶结点能带来决策树泛化性能的提升，将该子树替换为叶结点

是否应该进行这个划分，预剪枝要对划分前后的泛化性能进行估计，比如使用精度，用验证集算出划分前后的精度，如果划分后的精度有所提升，则划分，否则就作为叶子结点

感知机由两层神经元组成。

## 误差逆传播算法
多层网络的学习能力比单层感知机强。欲训练多层网络，简单感知机学习规则显然不够，需要更强大的算法。

误差逆传播（BP）算法是最杰出代表。

一般说BP网络指的是BP算法训练的多层前馈sj网络。

![2026-03-02-20-37-22.png](./images/2026-03-02-20-37-22.png)

![2026-03-02-21-11-18.png](./images/2026-03-02-21-11-18.png)

BP算法的目标是要最小化训练集D上的累计误差 $E=\frac{1}{m} \sum_{k=1}^{m} E_k$ (累积误差逆转传播算法)

BPsj网络经常遭遇过拟合，有两种策略：
- 早停，将数据分成训练集和验证集，训练集用来计算梯度、更新连接权、阈值，验证集估计误差，若训练集误差降低单验证集误差升高，则停止训练
- 正则化：在误差目标函数中增加一个用于描述网络复杂度的部分，例如连接权与阈值的平方和
- ![2026-03-02-22-32-40.png](./images/2026-03-02-22-32-40.png)
- 这样做是为了限制w的大小，因为过拟合经常出现参数非常大的情况


## 全局最小与局部最小
可能存在多个局部最小，但只会有一个全局最小

现实任务重常用以下策略跳出局部极小：
- 多组不同参数值初始化多个神经网络，按标准方法训练后取其中误差最小的解作为最终参数
- 使用模拟退火技术，在每一步都以一定概率接受比当前解更差的结果，从而有助于“跳出”局部极小
- 用随机梯度下降，随机梯度下降法在计算梯度时加入随机因素，即使陷入局部极小点，它计算出的梯度仍可能不为0，这样就有机会跳出极小继续搜索

# 第十五章 规则学习
## 基本概念
从训练数据中学习出一组能用于未见示例进行判别的规则。

![2026-03-25-22-58-50.png](./images/2026-03-25-22-58-50.png)

与神经网络，支持向量机这样的“黑箱模型”相比，规则学习具有更好的可解释性。

规则集合中每条规则都可看做一个子模型，规则集合是这些子模型的一个集成。当同一个示例被判别结果不同的多条规则覆盖时，称发生了冲突，“冲突消解”的方法有投票法，排序法，元规则法等。

规则分两类：
- 命题规则：简单的原子命令与逻辑连接词
- 一阶规则（关系型规则）：包含命题规则，复杂的多，相当于多了一个函数表达，能描述事务的属性或关系

## 序贯覆盖
也叫“分治策略”，在训练集上每学到一条规则，将该规则覆盖的训练样本去除，然后以剩下的训练样本组成训练集重复上述过程

最简单的方法是从空规则开始，将正例类别作为规则头，再逐个添加条件。

e.g

好瓜<-(色泽=青绿)  符合条件的存在正反例 再添加条件
好瓜<-(色泽=青绿)^(根蒂=蜷缩) 符合条件的存在正反例 换值
好瓜<-(色泽=青绿)^(根蒂=稍蜷)  以此类推，不断尝试直到规则集覆盖了所有正例


基于穷尽搜索的做法会由于组合爆炸而不可行，所以有两种策略来产生规则：
- 自顶向下
  - ![2026-03-28-21-41-32.png](./images/2026-03-28-21-41-32.png)
  - 贪心算法的通病：容易陷入局部最优
  - 解决方法：采用集束搜索
- 自底向上
  - IF 色泽=青绿 AND 敲声=浊响 AND 纹理=清晰 → 好瓜
  - 泛化规则：删除一个条件 IF 敲声=浊响 AND 纹理=清晰 → 好瓜 依然正确就再删除
  - 得到规则： IF 纹理 = 清晰 → 好瓜  然后删除覆盖样本，再继续学习下一条规则

## 剪枝优化
规则生成本质是贪心算法，需要有一定的机制缓解过拟合风险，常见是剪枝。

预剪枝：
例如用CN2算法，用似然统计量LRS衡量规则集覆盖样例的分布与训练集经验分布的差别。LRS越大，说明采用规则集进行预测与直接使用训练集正、反例比率进行猜测的差别越大。


后剪枝：
常用“减错剪枝”，划分训练集和验证集，从训练集上学得到规则进行多轮剪枝，每轮删除某个或多个文字，然后用验证集对将至参数的所有候选规则进行评估，保留最好的规则集进行下一轮剪枝。

# 第十六章 强化学习
## 任务与鉴赏
有监督无监督学习都是根据已有数据总结规则。

强化学习则通过与环境不断交互，通过试错和奖励反馈逐步学习最优策略，适用于难以直接判断每个动作对最终结果影响的问题。

![2026-03-28-23-29-35.png](./images/2026-03-28-23-29-35.png)

对于奖励，看的是累积奖励，因为像阿尔法狗下围棋，某一步在当前来说可能是最优的，可是对于全局来说可能是一个败子。

强化学习是要对环境进行建模。

每种状态下需要做什么动作，做了这个动作后状态直接会有一个什么样的迁移，会有一个转移状态概率。

强化学习任务对应四元组  E = {X, A, P, R}
- X 状态的集合
- A 动作
- P 当前状态选择当前动作后状态会有一个怎样的转移，X * A * X => 实数 指定状态转移概率
- R 收益  X * A * X => 实数 奖赏函数也可能仅和状态转移有关 X * X => 实数


机器要做的是通过环境中不断地尝试而学的一个策略$\pi$

根据策略，在状态x下能得知要执行的动作 $a = \pi(x)$

策略有两种表示方法：
- 将策略表示为函数$\pi:X=>A$
- 概率表示 $\pi:X \times A => \mathcal{R}$
 
$\pi(x, a)$ 为状态x下选择动作的概率，于是有 $\sum_a \pi(x, a) = 1$

学习目的：找到能使长期累积奖赏最大化的策略

长期累积奖赏常用方式：
- T步累积奖赏
- r折扣累积奖赏

## 有模型学习
现实是我们的动作会对环境产生影响，这是摇臂赌博机没有体现到的。

模型已知：机器已对环境进行建模，能在机器内部模拟出于环境相同或近似的情况。在已知模型的环境中学习称为“有模型学习”。

假设：
- 知道做了动作a，环境从什么状态转化为什么状态 转化的概率P是知道的
- 知道环境所处状态，做了动作a会得到什么奖赏 带来的奖赏R也是知道的

目的：累积奖励表达出来，并极大化它

### 策略改进
对某个策略的累计奖赏评估后，若发现它不是最优策略，当然希望对其进行改进，离线的策略应能最大化累计奖赏。

策略 π：干了就浇水，杂草多就除草
策略评估做的事是：这个种法 → 平均收成是多少？

已有价值函数
        ↓
更新策略，让它更优

发现：中午浇水效果不好，晚上浇水更好
修改策略：改成晚上浇水

### 时序差分学习
蒙特卡洛是多次尝试后求平均作为期望累积奖赏的近似，是批处理进行，在一个完整采样轨迹完成后再对所有的状态-动作进行更新

其实可以得到一个奖励就更新上去。

修正方向 = 当前奖励 + 未来估计 − 原来的认知

## 模仿学习
前提：有人类示范告诉AI什么环境下该做什么。

### 直接模仿学习
给的数据很全，所以直接用可监督学习学的符合人类增加决策轨迹数据的决策。

状态作为特征，动作作为标记，学的策略模型。

### 逆强化学习
从人类专家提供的范例数据中反推出奖赏函数。

前面是从奖励函数出发得到决策。这里是从专家给出的决策反推奖励函数。

![2026-03-29-23-18-17.png](./images/2026-03-29-23-18-17.png)

观察一个经验丰富的农民：他什么时候浇水，什么时候施肥，什么时候除草
并不知道：他的“评分标准”（奖励函数）
逆强化学习：通过观察他的行为，推测什么样的结果对他来说是“好”的
结果：他可能在最大化  产量 - 用水成本 - 劳动成本（奖励函数）

作用：直接模仿是看到什么做怎么，一旦环境变了就无法做出判断。得到奖励函数的话，环境改变还能自己决策。
